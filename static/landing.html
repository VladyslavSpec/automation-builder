How it works

From idea to automation in 3 steps

No onboarding calls. No documentation rabbit holes. Just open the editor and start building.

Step 01

Drag nodes onto the canvas

Pick from 22 pre-built nodes — triggers, YouTube, Telegram, AI, Twitter, Notion, Google Sheets, HTTP, and more. Drag, drop, done.

Step 02

Connect and configure

Wire nodes together by drawing connections. Use {{trigger.field}} templates to pass data between steps automatically.

Step 03

Run and watch it work

Hit Run. Watch each node light up in real time. Inspect inputs and outputs at every step. Set up a webhook trigger to run automatically.
